# UXL project directory

Six core libraries provide building blocks for accelerated computing. Choose by
the work you need to do, then use the project's documentation for installation,
examples and supported platforms.

[Foundation home](README.md) · [Working Group](https://github.com/uxlfoundation/open-source-working-group) · [Dynamic oneAPI specification](https://uxlfoundation.org/specifications/oneapi/technical-overview/)

## Choose a library

| Library and source | What it helps you do | Documentation |
| --- | --- | --- |
| [oneDNN](https://github.com/uxlfoundation/oneDNN) | Accelerate deep-learning operations such as matrix multiplication and convolution | [oneDNN guide](https://uxlfoundation.github.io/oneDNN/) |
| [oneDAL](https://github.com/uxlfoundation/oneDAL) | Accelerate data analytics and machine-learning algorithms | [oneDAL guide](https://uxlfoundation.github.io/oneDAL/) |
| [oneMath](https://github.com/uxlfoundation/oneMath) | Use SYCL interfaces for math routines across supported library backends | [oneMath guide](https://uxlfoundation.github.io/oneMath/) |
| [oneTBB](https://github.com/uxlfoundation/oneTBB) | Add CPU parallelism with tasks, parallel algorithms and concurrent containers | [oneTBB guide](https://uxlfoundation.github.io/oneTBB/) |
| [oneDPL](https://github.com/uxlfoundation/oneDPL) | Use parallel C++ algorithms on supported CPUs and accelerators | [oneDPL guide](https://uxlfoundation.github.io/oneDPL/) |
| [oneCCL](https://github.com/uxlfoundation/oneCCL) | Use collective communication in distributed computing and deep learning | [oneCCL guide](https://oneapi-src.github.io/oneCCL/) |

## Start with the project's guide

Installation methods, compiler requirements and hardware coverage vary by project
and backend. Check the project's current requirements and run a documented example
before integrating it into a larger application. Each source repository links to
its contribution guide, issues and release information.

For a library bug or feature request, open an issue in that library's repository.
For shared infrastructure or proposals spanning multiple projects, use the
[Working Group](https://github.com/uxlfoundation/open-source-working-group).

## Tools and shared work

- **[oneAPI Construction Kit](https://github.com/uxlfoundation/oneapi-construction-kit):**
  tools for bringing SYCL and oneAPI to new accelerators.
- **[UXL agent skills](https://github.com/uxlfoundation/skills):** guidance and
  evaluations to help AI coding agents use UXL libraries.
- **[Public CI requirements](https://github.com/uxlfoundation/open-source-working-group/blob/main/project-infrastructure/project-ci-documentation.md):**
  reported project infrastructure and testing needs.

For a broader introduction to the foundation and its projects, visit the
