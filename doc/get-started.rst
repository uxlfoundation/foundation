Getting started with UXL projects
=================================

Start with the `UXL project directory <../PROJECTS.md>`_ to choose a library and
find its documentation, installation guidance and source repository.

The directory covers oneDNN, oneDAL, oneMath, oneTBB, oneDPL and oneCCL, along with
links to the oneAPI Construction Kit and shared work on agent skills and public
CI. Each project maintains its own platform requirements and contribution guide.

For questions spanning projects, join the
`Working Group <https://github.com/uxlfoundation/open-source-working-group>`_.
