Web hosting
=============

The `project directory <../PROJECTS.md>`__ links to current documentation sites.
The `dynamic oneAPI specification
<https://uxlfoundation.org/specifications/oneapi/technical-overview/>`__ is the
current specification entry point. The retired bundled-specification site is
a historical resource.

Plan a documentation site
---------------------------

* Identify the content repository and its maintainers.
* Choose a publishing process that supports the project's documentation tooling.
  `GitHub Pages <https://pages.github.com/>`__ is an option for static sites.
* Document the deployment workflow, publishing permissions and support contact.
* Distinguish release documentation from current development documentation and
  preserve stable links between them.

Domains and changes
---------------------

Coordinate requests under ``uxlfoundation.org`` with foundation operations.
Include the hostname, destination, content owner and proposed migration plan.
Domain ownership, DNS administration and content publishing are separate
responsibilities and should each have a confirmed contact.

When moving a site, inventory existing URLs, arrange redirects where possible,
and verify inbound links and HTTPS after deployment. Moving a repository alone
does not establish that its documentation URLs have been redirected.

Foundation website
--------------------

The `foundation website <https://uxlfoundation.org/>`__ and
`website source repository <https://github.com/uxlfoundation/uxlfoundation.org>`__
are reference points. Confirm the production publishing process with foundation
operations before proposing deployment or DNS changes.
