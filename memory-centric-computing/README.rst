Memory Centric Computing SIG
============================

The UXL Foundation lists Memory Centric Computing among its active Special
Interest Groups on the `community participation page
<https://uxlfoundation.org/community/contribute/>`__.

The Linux Foundation's `December 2025 announcement
<https://www.linuxfoundation.org/blog/linux-foundation-newsletter-december-2025?hs_amp=true>`__
reported the group's creation, spearheaded by Hanwoong Jung (Samsung).
This is the announcement's attribution; current chair and contact details should
be confirmed through the group before being updated here.

Participation
-------------

Use the `UXL mailing lists <https://lists.uxlfoundation.org/groups>`__ to find
the group and receive invitations. Consult the `foundation meeting calendar
<https://zoom-lfx.platform.linuxfoundation.org/meetings/oneapi?view=list>`__ for
published sessions. A recurring schedule and meeting records have not yet been
added to this directory.

For current specification concepts and project documentation, start with the
`dynamic oneAPI specification
<https://uxlfoundation.org/specifications/oneapi/technical-overview/>`__.

To add an agenda, minutes, or confirmed participation details, follow the
`contribution guide <../CONTRIBUTING.md>`__ and link published records here.
